# Structured AI datasets

These are real, compact datasets used to test and teach AnyLearning's Tabular
AI and Text AI workspaces. The normalized CSV files are generated by
[`prepare.py`](prepare.py) directly from the recorded upstream sources. The
script also emits `catalog-v1.json` with byte sizes and SHA-256 checksums for the
AnyLearning CDN.

| Dataset | Workflow | Rows | Target | License |
|---|---:|---:|---|---|
| UCI Bank Marketing | Tabular classification | 45,211 | `y` | CC BY 4.0 |
| UCI Concrete Compressive Strength | Tabular regression | 1,030 | `Concrete compressive strength` | CC BY 4.0 |
| Banking77 | Text classification | 13,083 | `intent` | CC BY 4.0 |
| TruthfulQA | Response evaluation | 790 | `reference_answer` | Apache 2.0 |

The app records the dataset name, source, citation, license and input checksum
inside every project created from this catalog. CC BY attribution must be kept
when redistributing these files or derived datasets.

## Rebuild

```bash
python -m pip install pandas xlrd
python structured/prepare.py
```

The resulting files live under `structured/v1/`. Compare the generated hashes
against the currently published catalog before replacing CDN objects.

## Sources

- Concrete Compressive Strength: I-Cheng Yeh (1998), UCI Machine Learning
  Repository, [DOI 10.24432/C5PK67](https://doi.org/10.24432/C5PK67).
- Banking77: Casanueva et al. (2020),
  [task-specific-datasets](https://github.com/PolyAI-LDN/task-specific-datasets),
  arXiv:2003.04807.
- TruthfulQA: Lin, Hilton and Evans (2022),
  [official repository](https://github.com/sylinrl/TruthfulQA),
  DOI 10.18653/v1/2022.acl-long.229. The `candidate_response` field is the
  benchmark's supplied Best Incorrect Answer, not a claimed model output.
