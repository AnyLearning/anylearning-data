# Dataset licences

AnyLearning ships as a closed-source commercial product, and these datasets are
used to train, test, and demonstrate it. Every dataset here therefore needs a
licence that permits commercial use and redistribution. See
`anylearning/docs/model_license_policy.md` for the equivalent policy on models.

Record the licence **and its source** for each dataset. "It was on the internet"
is not a licence.

## Fetch-on-demand datasets

`vertebral_keypoints` contains instructions but no source pixels in Git. The
Spondylolisthesis Vertebral Landmark v1 record publishes the archive under
CC BY 4.0 while describing a mixture of locally collected and BUU-LSPINE source
images. A versioned 64/16-image engineering subset is therefore mirrored on the
CDN with `ATTRIBUTION.md` embedded in both archives. The complete dataset stays
fetch-on-demand from its DOI, and neither the subset nor its measured result is
clinical validation.

## Needs a licence decision before use

Two datasets in this repository have no recorded licence. Until that is resolved
they should not be used in shipped examples, marketing material, or bundled
sample projects. `tests/fixtures/datasets.py` in the main repository deliberately
does not load them.

| Dataset | Task | Status |
|---|---|---|
| `neu_surface_defect` | Image classification | **No README, no licence recorded.** NEU-DET originates from Northeastern University and is generally distributed for academic/research use, which is *not* the same as a commercial grant. Needs the upstream terms confirmed and written down. This is the dataset referenced by `docs/how_to_create_new_trainer.md`, so it is currently the documented onboarding example — worth resolving early. |
| `dental_segment` | Instance segmentation | **No licence in `README.roboflow.txt`.** Roboflow exports normally carry a licence line; this one does not. Confirm the licence on the source Roboflow Universe project and record it. |

## Adding a dataset

1. Confirm the licence permits commercial use **and** redistribution.
2. Reject anything non-commercial (CC BY-NC, "research only", "academic use").
3. Treat ShareAlike (CC BY-SA) with care: it is usable, but derivatives inherit
   the term. Prefer fetch-on-demand over committing such data here.
4. Add a `README.md` to the dataset folder recording licence, source URL, task,
   and any citation the licence requires.
5. Add a row to the table above.
